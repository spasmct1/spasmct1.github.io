## 🚀 Getting Started
Welcome to sambam! This tool helps you easily share files over your local network with Windows or macOS devices. No complicated setups. Just one command to get everything running.

## 🖥️ System Requirements
- **Operating System**: Windows 10 and above, macOS 10.13 and above
- **Network**: A local network connection (ethernet or Wi-Fi)
- **Disk Space**: At least 50 MB free

## 📂 Features
- Quick setup with a single command
- Supports Windows and macOS clients
- User-friendly interface for simple file sharing
- Secure file transfers within your local network
- Lightweight design for minimal resource use

## 📄 Using sambam
To share files, you will run a simple command in the terminal. Here’s how:

1. Open the Command Prompt (Windows) or Terminal (macOS).
2. Type the provided command:
   ```
   sambam share
   ```
3. Specify the folder you want to share. For example:
   ```
   sambam share /path/to/folder
   ```
4. Press Enter. Your folder is now shared on the network!
